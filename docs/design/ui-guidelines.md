# Web UI 实施规范

本文件收录截至 v0.1.4 已在实际页面确认的样式与交互，作为[权威设计 §5](2026-08-22-kist-v0.1-design.md#5-技术选型)的实施补充。设计文档决定语义，组件与 CSS 决定实际数值；不要再维护一套独立的尺寸常量。改动时同时检查这里的约定是否仍成立。历次取舍及证据见[2026-10-17 复盘](../plans/2026-10-17-ui-release-retrospective.md)。

## 从共享入口修改

| 需求 | 优先修改或复用的位置 | 边界 |
|---|---|---|
| 按钮、菜单、弹窗的基础外观 | `web/src/theme.tsx` 的 Mantine 主题 | 不给同类控件另造皮肤 |
| 页面标题与右侧操作 | `App.tsx`、`.page-header`、`.header-actions` | 归档盒是参照；全部文件、回收站、历史共用规则 |
| 搜索、排序、显示方式工具栏 | `Filters.tsx`、`DisplayMode.tsx`、CSS 工具栏变量 | 图标按钮方形，与搜索框同高、上下行同列对齐 |
| 可搜索单选、标签选择 | `Select.tsx`、`Tags.tsx` 的 `TagSelect` | 搜索草稿与已选值分开，不要求先删除当前值 |
| 弹窗和退场 | `Dialog.tsx`、`DialogPresence` | 由共享生命周期管理动画和焦点 |
| 右键与行尾操作 | `ContextMenu.tsx`、`EntryActions.tsx`、`SidebarMenuButton.tsx` | 同一动作共用业务处理，不能只补一个入口 |
| 文件/目录网格与列表 | `FileGrid.tsx`、`icon-grid.ts` | 同一滚动区域；保留虚拟化、分页与目录排序语义 |
| 年/月/日精度日期 | `PartialDateInput.tsx` | 不把年/月偷偷补成某一天 |
| 文件信息和元数据 | `FileDetail.tsx`、`.file-info-panel` | 展示格式不修改原始值或日志 |

开始改像素前，先定位真正拥有布局的元素。例如历史页的标题在 `App.tsx`，不在 `History.tsx` 的内容 section 内。先对照计算样式和元素边界，区分容器 padding、子项 margin、边框、行高；截图像素还受缩放和设备像素比影响。

## 视觉层级

- 控件使用 Mantine 的中性底色、边框和主色语义变量，验证浅色、深色与亮主色；不恢复旧的多套全量皮肤。
- 主色选择复用 `ColorChoiceGroup`：平面的圆角矩形色块与颜色名称组成整项单选按钮，选中使用外侧描边与浅底色，不再并列两个圆形标记；保留单选语义、键盘方向键和禁用状态，窄屏自然换行。
- 普通操作统一用 Mantine `Button` 的默认描边外观。下载需要链接语义时使用 `Button component="a"` 并保留 `href` / `download`，不要另写类似按钮的 `<a>` CSS。纯文字辅助操作可以使用主题色，禁用态交给组件。
- 标题、字段、值分层：字段和辅助说明用较小的次要文字，值保持可读。普通范围提示不使用醒目的黄色警告条；真正的警告与不可逆边界另行表达。
- 详情中的文件 ID、文件组合 ID、校验值使用 11px 等宽字体，比普通字段值的 13px 小 2px，明确区分标识符与正文。复制入口保持普通字段的字体和字号；长值仍单行省略并支持复制完整内容。此前曾统一为 13px，但等宽字体在相同字号下仍显得大小不一致，用户于 2026-10-26 确认改为有意拉开视觉层级。
- 相关控件的尺寸与间距从同一规则派生。工具栏复用 `--toolbar-control-size` / `--toolbar-control-gap`，不逐页猜测宽高。改完同时检查归档盒、盒内目录、全部文件、历史和回收站。
- 同一信息组内部紧凑，组间保留更大间距；避免每个元数据项再套卡片或粗分隔线。长名称、路径和 ID 允许换行或有依据地截断，不挤掉操作按钮。
- 归档盒页头按标题与日期、描述与标签、子目录面包屑的顺序排列；标签属于归档盒信息，位于面包屑上方。标题与标签作为信息组，页头操作顶端对齐标题；面包屑在页头下独立成行并靠近搜索栏，作为导航组，不使用负 margin 挤压相邻行；盒内最外层也显示面包屑。路径统一为「根目录 › 归档盒 › 子目录」：根目录返回所有归档盒，归档盒返回当前盒最外层并在悬停时显示实际盒名；不重复显示盒名与开始时间。
- 归档盒列表与图标视图展示直接附加的标签，沿用详情页吊牌样式；归档盒及文件列表的标签在名称区域靠右对齐，无标签时不留占位。优先保留标签，描述过长在末尾显示省略号，名称也允许截断。标签仅作展示，点击条目仍打开归档盒或文件；极窄空间及长标签允许截断。
- 样式替换后搜索所有旧类名和入口；仍有调用者时统一迁移，最后删除失去用途的 CSS。不要以不断追加覆盖规则代替清理。

文件缩略图统一等比完整显示，允许留白，不裁切填满卡片；适用于所有图片格式及视频封面，大／中／小图标、列表和画廊开合动画保持一致。MOV 与其他视频共用取帧预览，PDF 显示首页静态缩略图，详情使用随页面主题的 PDF.js 阅读器，支持翻页、缩放、文本选择和搜索；默认使用 PDF.js 自动缩放，大屏最多 125% 并居中留白，小屏适应可用空间，用户仍可主动选择适合宽度或手动缩放；顶部“…”更多菜单提供新标签页打开原 PDF 与下载入口，读取失败时提供说明和重试，STL 显示完整模型的固定视角静态图；GPX 网格显示完整轨迹地图，详情可缩放，地图内触摸拖动不触发画廊切换文件，地图失败时保留轮廓并说明背景不可用；无预览格式显示完整类型图标，列表中省略图标内的重复类型文字。

## 已确认的交互

### 搜索与选择

- 条件块使用统一浅底；字段与运算符小一号、加粗且颜色较浅，值用主题色。取消早期分段白缝、内描边及值区域独立底色。不要把真实标签的吊牌形状套到搜索条件上。
- 字段/运算符/值可分别编辑。无字段文字是关键词；候选使用“搜索此文本”，不重复输入内容。草稿执行、重复条件、旧收藏分组兼容及目录范围遵循权威设计 §5.5，不能仅为外观改变查询语义。
- 当前目录内搜索包含其子目录；范围提示使用次要文字，不能把“正在搜索”用于一个静态范围说明。空结果提供清除筛选入口，并说明其作用。
- 归档盒和标签选择都支持搜索。搜索框放在下拉层内，打开聚焦空搜索，关闭清除搜索草稿而保留已选值；菜单内滚动、通过 Portal 避免被弹窗裁切。
- “所有记录”“选择标签”“无父标签”等范围/占位项与真实对象区分，用较小浅色文字和分隔；“选择标签”不提交业务写入。有起始日期的归档盒可显示浅色小号日期，无日期则不补占位。
- 添加标签弹窗使用小号宽度，正文不重复“标签”标题；已附加标签与选择框分组排列，无标签时不留空行。弹窗内不沿用页面区块的上下外边距。添加标签弹窗初始焦点落在标签选择框，异步加载后也保持这一行为；关闭按钮保留正常焦点样式。添加标签选中即提交，沿用失败反馈和幂等重试；不再要求第二次点“添加”。日期在当前年/月层级提供确认，并提供“今天”，底部文字操作使用主题色，不同时摆出三套选择控件。

### 标签、详情与历史

- 已附加标签采用紧凑吊牌背景，左侧尖角及小圆孔；没有额外标签 icon、常驻 X 或为 X 保留的空位。删除通过共享右键菜单，保留键盘菜单入口；涉及触屏时实际验收菜单可达性，不把桌面右键测试当作触屏证据。
- 桌面画廊详情开关在右侧整条 48px 边缘区域悬停时显示，不必命中中央箭头；预览为边缘区域留出空间，避免拦截 PDF 滚动条、地图和媒体操作。键盘聚焦仍显示，触屏常显。
- 文件详情默认关闭；用户开关状态在当前浏览器持久化，刷新保留，存储不可用时本次会话仍能操作。默认状态、用户偏好与 URL/查询状态须分别管理。
- 基本信息、标签和元数据分组展示。分组标题为 EXIF、GPS、File、Media，标题加粗；`gps:` 字段按命名空间独立显示为 GPS，其余字段按来源分组，底层提取来源不变；已知 key 本地化；未知 key 的显示名称仅保留第一个 `:` 后的字段名，不重复命名空间，编辑入口使用同一名称。完整 key 仍通过悬停／键盘聚焦提示查看，存储与请求中的 key 不变。中文字段名优先压缩在七个汉字的显示宽度内，省略分组已说明的内容和冗余修饰（如「置信度」「正文」、GPS 内的「日期／时间」），保留拍摄／数字化、方向／方位等必要区分；原始 key 通过悬停提示查看，不为冗长名称扩大字段列。`media:kind` 为“类型”，`media:mime` 为“MIME 类型”。`file:mtime` 按原始纳秒时间戳格式化，悬停仍可查看原值。
- 可重新提取的元数据模块在标题右侧统一提供「重新提取」：鼠标悬停整组时显示，键盘聚焦时显示，触屏常显；排队、运行和失败时保持入口可见。GPS 与 EXIF 共用提取任务，File 导入事实不提供此操作。旧值保留到新结果成功写入。已有结果的任务排队／处理状态统一由标题右侧同一个禁用操作按钮展示，不另占正文行或增加第二个按钮；后台暂停的待办仍显示可点击的「重新提取」。后台任务尚无任何 metadata 时不显示空模块，成功写入结果后出现；未发起任务时的首次手动提取入口保留，同样位于标题右侧，复用紧凑文字按钮；首次排队与运行不另占正文状态行，所有元数据任务（包括方向、OCR、描述、结构化提取和位置查询）统一显示「正在提取」，设置页队列共用「正在提取：{文件名}」。原先按任务类型区分运行文案，现改为共享文案，避免前端维护类型分支。仅在未连接或未选择默认模型时显示标题右侧的「AI 设置」及小号辅助说明，配置完成后不常驻设置链接。
- 原始 key/值提示即时出现，鼠标提示靠近指针下方、边缘避让，半透明深底；键盘聚焦也能查看。避免固定在右侧挡住 value，不以浏览器原生 `title` 的延迟作为唯一入口。鼠标浮动提示统一经共享 `FloatingTooltip` 管理：异步更新移动目标后，即使没有触发目标的 mouseleave，鼠标移到目标之外也必须关闭；滚动、窗口失焦及 Escape 同样关闭，避免残留浮层。键盘聚焦提示保持独立。
- 描述正文与 OCR 识别文字复用长文本预览：正文压缩空白并最多展示三行，复制与悬停提示保留完整原文及真实换行。「复制」统一位于末行右侧，短值也右对齐，不紧跟 value；只在末行留出复制空间，不压缩前两行宽度。整段预览与末行「复制」共用一个原生按钮，点击正文或按 Enter / 空格均复制完整原文，反馈与 ID 字段一致；编辑图标独立，不触发复制。长文本悬停提示复用元数据的半透明浮动提示，在鼠标右下方展示并跟随鼠标，限制在视口内；键盘聚焦与触屏仍使用可滚动的定位提示。
- 画廊初始焦点落在非操作性容器，避免“返回列表”像被选中。稳定 ref 与焦点陷阱绑定，异步数据更新不抢走焦点；保留 Tab 导航和按钮可见焦点，不能全局取消 outline。
- 历史列表在打开详情前就能看出对象和变化；ID 作为辅助标识。按需获取摘要，事件保存的名称优先于当前名称，使用当前名称时明确标记。不要为了摘要把整批 payload 发给列表。

设置字段在标题行最右侧以主题色、小号文字常显「已显式指定」，按显式配置来源判断，不比较其值与默认值是否相等。恢复入口位于标记左侧，桌面仅字段悬停／键盘聚焦时显示，触屏常显；隐藏恢复入口不隐藏显式来源标记。跟随默认以灰色「已跟随默认」在字段悬停／键盘聚焦时显示，触屏常显，不显示恢复入口。普通字段、GPS 与 AI 开关共用该组件和样式，草稿编辑／恢复即时反映来源变化，保存才持久化。

设置页面顶部的保存与重新加载统一覆盖普通设置、GPS 和 AI 配置，分区内不重复放保存按钮；允许同时编辑不同分区。校验统一由后端在保存时进行；失败保持配置原子性，在响应中给出具体字段与稳定错误码，前端只负责翻译和显示，不维护第二套规则。字段附近显示错误并定位首个出错字段，修改或恢复该字段时清除旧错误，重试保存时重新校验。重载会撤回全部配置草稿，保存失败保留全部草稿。登录、断开连接与后台任务等即时动作仍保留独立入口。 保存按钮在无修改时提示“没有未保存的修改”，复用半透明、跟随指针的完整文本浮窗，通过外层目标支持原生禁用按钮的悬停与键盘聚焦，不另占说明行。可保存或正在提交时关闭禁用原因提示。

未保存状态按最终值和配置来源与保存快照的差异计算，不按是否发生过编辑计算。显式指定的值改回原值时清除差异；继承字段编辑后恢复继承也清除差异；数值相同但继承／显式来源改变仍须保存。容量按字节比较，列表按保存时的去空白、空项规则比较，同时保留原始输入草稿，避免打字过程中的空行被清掉。

设置页存在普通设置、GPS 或 AI 的未保存配置草稿时，站内跳转使用共享弹窗提供「保存并离开／放弃并离开／继续编辑」，默认聚焦继续编辑；保存失败保留页面、草稿和目标地址，并在弹窗显示错误。侧栏导航、当前标签页链接和浏览器前进／后退均保护草稿，同页目录跳转不拦截。浏览器关闭、刷新及跨文档历史跳转采用原生 `beforeunload` 提醒，浏览器不允许自定义其文案或加入保存按钮，不承诺关闭时异步保存；无修改时不安装提醒。登录、任务控制等即时动作不作为配置草稿。

## 一轮 UI 修改的完成条件

1. 先说明当前问题和共享参照，确认是布局、视觉层级还是业务语义；直接实施已授权的小改动，不为颜色/间距反复索要许可。
2. 一次收齐同一问题涉及的页面、状态和入口。检查 normal / hover / focus / disabled / loading / empty，按影响验证长文本、小屏、深色和 RTL。不要只截图静态正常态。
3. 行为变化运行对应组件测试；数据契约、默认状态、文案和 API 请求变化同步 `web/visual/tests/`。可逆的纯样式微调不必编写复刻 CSS 的单元测试。
4. 代码交付运行 `make check`。若使用嵌入式本地预览，构建并重启确认过身份的本地进程，再刷新浏览器；不要验收旧二进制，也不要误停其他实例。
5. 浏览器看实际效果和相邻页面；语义断言验证功能，截图审阅验证外观。尺寸问题可读取元素边界/计算样式，不能只凭肉眼猜测。
6. 独立阶段及时提交推送；依[视觉流程](../testing/visual.md)处理对应 SHA 的检查结果。设计仍在迭代时不必每改一个像素就接受一次基准，但完整采集失败必须及时修复，不能积到发版当天。

Word 与 PowerPoint 文件详情复用 PDF 阅读器与自动缩放规则，转换期间沿用派生任务状态／取消／重试。转换就绪后顶部并排提供“在新标签页打开 PDF”和“下载原文件”，前者打开转换结果，后者始终下载 DOC/DOCX/PPT/PPTX。幻灯片缩略图保留原始宽高比并完整显示。

PDF、Word、PowerPoint 详情采用淡入，不执行缩略图飞入，因为阅读器页面与图片铺满预览区的几何规则不同。阅读器加载提示覆盖在固定的页面区域内，不占额外布局高度；以首个页面绘制完成（而非页面初始化）为显示时机，避免空白画布及加载提示消失造成二次缩放。遵循系统减少动态效果设置。

浏览器原生支持且原文件接口允许内联的图片，详情使用原图，保留透明度、动画与原始分辨率；与下载并排提供“在新标签页打开图片”。原图加载失败显示说明及重试。HEIC 等格式保留兼容预览，网格仍使用缩略图。

文本卡片显示有界开头片段，不生成图片；详情统一使用只读文本阅读器，行号、语法高亮、搜索与换行开关，跟随主题。TXT/LOG 默认换行，源码默认保留长行；无高亮语言的文本仍可阅读。截断必须说明显示与搜索范围，空文本与不可预览分开。文本区域的方向键和触摸交互不得切换画廊文件。

Markdown 详情默认排版预览，工具栏提供「预览 / 源码」切换，带行号链接自动进入源码。正文居中限宽并跟随主题，小屏表格和代码块可横向滚动；原始 HTML 不渲染，外部图片不自动加载，归档内配图与附件按相对路径解析，缺失引用明确提示。

表格详情使用共享只读阅读器外壳和工具栏，保留工作表切换、行列标题与分页，搜索明确限定当前页；单击、拖动或 Shift 选择单元格，可用复制按钮或 Ctrl/Cmd+C 复制 TSV。CSV/TSV 提供表格 / 源码与编码入口。卡片直接渲染小表格，深浅主题一致；公式不重算，旧 XLS 与截断情况明确说明。

表格详情改用 Univer 开源核心的只读画布，缩略图保留轻量 HTML。只读权限须明确允许复制、禁止修改，不能只隐藏编辑工具栏。页内选区、键盘移动与缩放交给组件；搜索定位与复制按钮接入同一选区，显示原文件行列编号。等待权限和渲染就绪后显示画布，主题与语言跟随应用；不在卡片加载 Univer。

文件空状态在剩余内容区内略偏上居中，图标、说明和上传按钮保持紧凑一组；小屏保留最小阅读高度并允许页面滚动。

设置字段的默认/自定义状态不常驻展示，由「恢复默认」可用状态表达；重启要求用标题旁的小号次要文字。时区含义及列表填写说明使用共享 `HelpTooltip`，复用文件组合的半透明浮动提示，以及键盘焦点和触屏展示。命令行覆盖和待重启等当前运行状态仍直接显示，避免用户误判生效值。

设置页（主库与离线客户端）及同步页的存储统计统一使用 `StorageUsageValues`，标签、数值、空值和间距由共享组件与 `.storage-usage-values` 管理；统计项横向采用较宽间距，窄屏自然换行。上述页面的 `.flat-page-section` 区块间距也保持一致，不以页面祖先选择器另行缩放。此前同步页单独增大统计间距、缩小区块间距的覆盖导致同语义布局分叉，现移除；用途不同的列表、画廊等布局不受此规则约束。

地图、文字地址和原始 GPS 字段统一放在 GPS metadata 模块，复用 GPX 的地图渲染、加载/失败/重试及来源署名；地图标记使用文件 GPS，文字地址标注“附近”。GPS 标题右上角复用共享任务按钮，分别提供原始 GPS 的「重新提取」和文字地址的「查询地址／更新地址」；地址缺失时查询入口常显。Photon 仅在服务商字段显示，OSM 署名与地图来源合并，地图失败或缺少可绘制坐标时保留署名兜底。位置设置复用现有设置区块与任务队列控件，但不使用 AI 登录、模型或 AI 设置文案。

GPS 标题旁的信息图标使用共享 `HelpTooltip` 说明地图标记与误差圈，支持悬停、键盘聚焦及触屏，不在地图下方常驻说明段落。

GPS 元数据小地图禁用滚轮缩放，鼠标位于地图上时滚轮仍滚动外层页面/详情面板；保留加减缩放按钮和触摸缩放。详情页的 GPX 轨迹地图保持原有滚轮缩放行为。

文件 metadata 的所有已显示值提供原地编辑：悬停值或键盘聚焦时在右侧显示编辑图标，触屏常显。编辑图标浮于值的右上方，不为隐藏图标固定留白，使用跟随主题的半透明毛玻璃底；与常驻人工来源图标一起按第一行文字的行盒垂直居中，仅人工来源标记保留空间。复用文件重命名的共享 `InlineValueEdit`；单行 Enter / 失焦保存、Esc 取消，多行保留原始换行，Enter 换行，Ctrl/Cmd+Enter 或保存按钮提交。编辑的是原始值而非格式化显示值。失败保留草稿并复用幂等重试反馈，不静默覆盖并发更新。人工来源使用最右侧的用户图标和共享浮窗说明，不再自动覆盖；编辑后仍按字段命名空间留在原分组。未改值退出不改变来源。原有格式化、复制及完整文字提示保持可用。

OCR 与描述各提供「补充信息」字段，可直接输入姓名、关键词或说明；使用现有 metadata 行、浮层编辑图标与人工来源，值按普通文本展示；没有复制按钮或点击复制行为，完整原文提示与 OCR／描述正文共用 `FullTextTooltip`。字段名与其他 metadata 共用 key 悬浮提示；共享 MetadataLabel 内的帮助图标使用行内紧凑尺寸，不撑高普通单行字段。输入框从一行开始随内容增高。编辑时显式「保存」或「保存并重新提取」，不因输入或失焦调用 AI。主库可以保存后启动任务，离线客户端仅保存；人工正文受保护时保留保存入口并禁用重新提取。只显示当前补充信息，不另存或展示生成时的补充信息快照；只有实际存在 hint 记录才显示字段，不由前端补造；首次生成时写入空字段，未编辑前不显示人工来源图标。

元数据值的编辑图标旁提供删除图标，共用悬浮毛玻璃样式和首行对齐，隐藏时不占正文宽度；两者按复制按钮的实际矩形避让，不以复制文字宽度代替位置；多行复制位于末行、或短文本复制不与图标相交时，图标保持首行右对齐。文本截断、换行和复制反馈变化后重新测量，人工来源标记仍在最右侧。删除需两次点击：首次仅在点击位置上方打开小号确认浮窗（键盘操作锚定按钮），确认按钮所在的右侧靠近触发点；上方空间不足时自动翻转，浮窗避开视口边缘，无页面中央遮罩；取消、Esc 或点击外部关闭，不提交写入。确认说明精简为「不会自动恢复，可在历史中撤销。」，通常保持一行，不强制禁止极窄屏换行；第二次明确确认才提交。提交期间禁止重复操作，失败保留浮窗并复用幂等重试。所有已显示字段，包括人工值与补充信息，行为一致。

图片方向、OCR 与描述统一在「模型」一行展示带服务商前缀的模型标识，不另列 AI 服务商；描述不再展示生成语言快照。资料库语言设置入口保持独立。GPS 地址查询的服务商字段沿用原有语义。

OCR、描述与图片方向的结果不再提供「源文件校验值」行或编辑／复制入口；输入版本保护由内部写入与替换生命周期维护，文件 ID 等标识字段的显示与复制不变。

结构化信息使用普通字段值与完整文本浮窗，不提供逐字段复制按钮或点击复制。单份证书的姓名、日期、地点等直接放在结构化信息下；仅多个人／多条记录保留必要分组。展示遵循 JSON fields／children 数组的原文顺序，不按 key 排序；字段命名遵循结构化提取设计中的简短通用语义。

提取区块的任务失败和操作失败统一用共享 `TaskError` 小号错误文字。状态刷新失败且已有成功状态时保留上次结果，不将瞬时连接故障显示为提取失败。单文件提取状态仅在排队或执行中每两秒刷新，连接失败后退避到十五秒；空闲状态通过已有资料库 revision 检查、页面返回与显式操作刷新，不为每个区块持续轮询。补充信息编辑器复用相同策略。

设置中的字段标题和帮助统一经 `SettingsFieldHeading`／`SettingsCheckbox` 展示，实例字段、AI 代理及位置接口共用标题行与半透明说明浮窗；辅助说明统一经 `SettingsHint`。AI 与位置的表单、操作和后台队列采用共享间距，后台任务复用访问凭据／离线保留内容的 `settings-table`，每类占一行，列为任务、状态、排队、失败与行尾操作。补全／重试／暂停（或继续）统一使用原生按钮语义的文字链接，保留键盘与 disabled 行为；可用时使用主题色，禁用时用灰字，无按钮背景，操作之间统一使用中等间距。操作列按内容分配宽度，其余空间留给状态。行尾操作与类型帮助图标在桌面悬停或键盘聚焦整行时显示，触屏常显，隐藏不改变列宽。类型说明放入行标题帮助，状态与错误在同一行紧凑展示，长内容省略并复用 `FullTextTooltip` 查看全文；数字列保留足够宽度且不换行，避免长错误挤压列宽或撑高整行。紧凑表格正文使用 13px 常规字重，表头和操作 12px，错误沿用 12px；操作不使用标题式粗体。窄屏横向滚动。六类队列集中放在独立的“后台任务”二级区块，按普通元数据、图片方向、OCR、描述、结构化信息、GPS 分行；目录提供独立锚点。各功能配置留在原区块，未保存时只禁用相关任务操作。共享调度器串行执行，普通元数据优先于 AI／GPS，同优先级轮转；各组保留独立暂停、重试与数量，不呈现为跨类型的严格先来先执行队列。共享执行与暂停语义放入区块标题帮助，并明确其范围不包含独立的缩略图／预览／转码执行器。`scanning` 只代表尚有扫描范围，显示“待查缺补漏”，不能据此声称正在执行；有运行中任务时优先展示运行状态，否则暂停优先于待扫描，已有待办显示“等待处理”，没有工作才显示空闲。提交补全不留下常驻提示；后端保留的队列错误标为“上次失败”，非暂停且没有失败项时不展示旧错误。

后台任务表格最左侧保留独立展开列，箭头复用标签树的 `TreeToggle`，桌面悬停或键盘聚焦整行时显示，触屏常显；点击只展开该类任务，不触发任务控制。展开明细直接放入原任务行的内容单元格，任务名与箭头保持左侧顶部，状态／数量／操作保持顶部对齐，汇总和明细之间不另设行边框；表头与各行通过共享列轨道对齐，操作列随内容确定宽度。子表格复用 `settings-table--dense`，正文 12px、表头 11px、上下内边距为普通紧凑表格的一半。展开区合并展示排队与失败任务，按持久任务位置分页，每页 20 项；正在执行的文件仍由汇总行展示，不混入历史记录。文件名直接链接详情，不另设“查看文件”按钮；归档盒名称与变精度开始日期复用图标视图的 `FileBoxSource`，使用当前归属与名称，文件已移除时保留任务名称但不提供失效链接。明细按需读取，收起停止明细请求，仅刷新当前页；暂停且无运行请求时停止明细轮询，汇总状态变化仍刷新可见明细。失败原因单行省略并提供完整文本浮窗，加载、空列表与读取错误均在展开区反馈，不改变汇总行状态。

配置项的“恢复默认”统一经 `SettingsFieldHeading` 的 action 槽放在标题行最右侧，复用小号文字链接。所有配置项均保留入口，允许恢复时使用主题色，已是默认值或草稿已恢复时灰色禁用；桌面悬停整项或键盘聚焦时显示，触屏常显，隐藏不影响标题行布局。先前完全不渲染默认项入口，用户无法发现恢复功能，因此改为悬停时保留禁用态。字段下方仅在实际存在启动参数覆盖或待重启说明时占行，不保留空的操作行。

帮助图标统一使用 `HelpTooltip` 的灰色次要文字色，并关闭主题自动对比度，悬停及聚焦时也保持灰色；复选框帮助图标与文字行框垂直居中，不添加人为像素位移。

带目录的设置／同步页面在首次加载或目录跳转后，跟随异步区块引起的内容尺寸变化校正锚点；滚轮、触摸、指针按下或键盘操作后停止自动校正，避免抢回用户的浏览位置。再次点击目录（包括相同 hash）或改变 hash 时重新启用校正；复用 `SectionIndex`，不增加轮询或全页等待。

设置页的独立本机配置与首屏队列状态由 `loadSettingsPage` 集中准备，子组件复用同一份查询定义和缓存，不依次挂载后再重复读取；模型列表和可能耗时的存储统计独立更新，统计从开始就显示固定结构与占位值。同步页的离线保留内容与本机历史首屏也与状态并行读取。权限检查依赖仍保留（不在不支持 AI 的实例预取受限接口），文件预览、所选历史详情等真实 ID 依赖保持按需读取。

2026-10-30 设置中的“照片位置”曾简化为“位置”；随后用户确认改为“GPS”，明确其数据来源，并将自动查询、补全、帮助和地图说明中的对象统一称为“文件”。实际仍仅处理支持读取 GPS 的文件，没有 GPS 的文件跳过，不扩大输入格式支持。资料库模式中“地图”紧接其后，“后台任务”始终位于最后，页面与目录保持相同顺序。

设置保存等操作失败的通用提示复用 `FloatingFeedback`：在视口顶部浮动，滚动不移出视野，不自动消失，可关闭且不遮断操作。关闭通用提示不清除字段错误、不丢弃草稿，也不自动重发请求；保存失败的离开确认继续保留。
