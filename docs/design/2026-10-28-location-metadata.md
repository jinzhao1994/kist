# 拍摄位置 metadata 与地图

用户授权采用无需账号或密钥的 Photon；地图沿用 MapLibre + OpenFreeMap 及现有配置。位置指照片 GPS 记录的拍摄位置，不是 OCR/描述中的机构地址。仅查询坐标，不发送图片或识别正文。

## 提取与持久化

独立 `geocoding` 配置：`automatic` 初版默认关闭；2026-10-29 用户确认新建资料库默认开启。为避免打开旧库时意外补查已有图片，旧配置未填写 automatic 时仍沿用关闭，已保存的开关选择保持不变；新建配置显式写入开启。`endpoint` 默认 `https://photon.komoot.io/reverse`，允许自部署 Photon。启用时记录当前 op 边界，仅处理之后导入的图片；已有图片显式补全。离线客户端只展示同步结果，不查询 Photon。

复用持久化后台队列、文件锁、失败暂停及显式重试，独立 `geo` 队列，不依赖 ChatGPT 登录或模型。后台按基础元数据 → 方向 → OCR → 描述 → 地址的固定次序串行推进；每个网络任务先补全基础提取，OCR/描述强制补齐缺失方向。地址不依赖方向，方向失败不阻止地址查询。各队列可独立暂停。

`geo:address`、`geo:provider` 由 `source=geo` 拥有；空地址表示未找到附近街道/片区。无有效 GPS 的图片只记提取完成，不请求外部服务。已有完成结果不重复查询，支持重新提取。

使用现有 `extract_metadata` action，不新增 schema/action。通过 library 写入，提交前检查文件、metadata 与提取版本快照，保护用户来源及墓碑。撤销、targets、索引、追赶、snapshot、rebuild 和深校验沿用原语义；重放不访问网络，不改变内容时间。

## 精度与来源

接受有效 WGS84 坐标（未声明基准时按通常 WGS84 解释），保留南/西半球及零坐标。未知基准不画图、不查询。

Photon 使用 `lang=default` 获取当地名称，限定 `street` / `locality`、1 km 半径，返回街道/片区，去重行政区名并展示为“附近”，不返回店铺/门牌。地图使用原始 GPS，不用 Photon 道路代表点。记录了定位误差时显示误差圈，否则不捏造误差。

用户允许误差小且唯一覆盖一栋建筑时提供楼号；但 Photon 公共结果 extent 是包围盒，不能证明建筑包含整个误差范围。当前保守退回街道/片区，未来有真实建筑边界再扩展。最近 POI 或 1 m 精度本身都不构成证明。

地图、文字地址和原始坐标合并在 GPS 模块；服务商字段显示 Photon，不重复链接。OSM 署名统一放入地图来源控件，地图失败或没有可绘制坐标时提供来源链接兜底。参考：[Photon API](https://github.com/komoot/photon/blob/master/docs/api-v1.md)、[公共实例说明](https://github.com/komoot/photon)。公共服务无 SLA，免费不代表无限使用。

## 限流与失败

每资料库使用专用 OS 文件锁串行请求；请求结束后的等待由 `geocoding.request_interval_seconds` 控制（0–86400 秒，默认 2 秒）；请求保持串行。下次允许时间在请求开始前预留、结束后更新到 `runtime.db` 的 `service_limits` 表，跨进程、重启仍有效。该状态可丢弃，权威地址在 ops 中。

429/503 尊重 `Retry-After`（秒或 HTTP 日期），网络错误至少退避 1 分钟；`geocoding.pause_on_error` 默认 true，单项查询失败时暂停队列；关闭后保留失败记录，等待服务冷却后处理其他照片，不自动重试失败项。队列自身的配置／存储故障仍暂停，避免持续错误。旧结果保留，不自动密集重试。20 秒超时、响应体上限、不跟随重定向，错误不回显包含私人坐标的 URL。多个资料库/NAS 无法共享全局限额，大规模使用需自部署。

测试和视觉场景只使用合成数据，个人图片、坐标、姓名与地址不进入 Git 或 CI。

2026-10-29 设置说明收拢到“拍摄位置”标题的共享帮助浮窗，只说明 Photon 根据 GPS 查询附近地址、无需密钥、请求串行且不发送图片正文。移除地图加载说明。接口相关字段按“Photon 接口地址 → 请求间隔（秒）→ 查询失败后暂停后台处理”排序。上述配置保存后热生效；等待服务限流／错误冷却的队列任务保持排队，不将等待本身记录为提取失败。

2026-10-29 设置区块显示名改为“照片位置”，与当前照片 GPS 来源对应，避免把文档中的地址误作照片位置。补全时复用结果及无 GPS 跳过的规则移入标题帮助，不再常驻于队列操作下方。各类后台队列仍独立，共享队列组件的暂停／恢复按钮统一简化为“暂停处理／继续处理”。
