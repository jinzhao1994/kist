# 统一实例设置

状态：用户已授权实现（2026-10-23）。补充权威设计中的配置和离线客户端部分。

## 配置归属

主库与客户端各有自己的 `kist.toml`，不经数据同步互相覆盖。两端提供「设置」页面，控制持久化配置；「显示设置」继续保存浏览器偏好。主题主色迁入实例配置，明暗模式、语言、格式、显示时区仍归浏览器。

原先主库 kist.toml、客户端 client.json / connection.json 及主库 sync-access.json 分散保存，且靠 kist.toml 是否存在识别主库。此方案已不适用：统一为带明确 mode 的配置；旧主库缺少 mode 时视为 library，旧客户端首次打开迁移成 client。同步日志、目录边界、缓存索引和离线保留选择是运行/操作状态，不改成设置项。

## 文件与修改语义

缺省项使用完整默认值；身份和数据解释所依赖的时区在初始化时固定。未知键、未知版本、无效值拒绝。实例 ID 与绑定库 ID 不允许通过设置编辑。配置携带凭据，统一以私有权限、原子替换与目录同步保存。读出 API 不包含凭据明文或摘要，替换凭据沿用连接验证流程。

UI 修改通过 library 编排，使用配置内容摘要检测过期编辑，并使用跨进程配置锁串行化程序写入；保存前重新读取，保留未修改项。尽量保留原文件注释与格式；无法安全局部替换的合法 TOML 使用语义等价编码，不静默丢弃未知键。恢复默认意味着删除显式项，而非固化当前默认值。

迁移先持久化完整新配置，再清理旧配置；中断后以新配置为准，避免旧凭据被重新导入。旧格式版本不认识时拒绝迁移。主库/客户端模式互相拒绝误开。

## 生效与入口

主题、缓存与连接修改即时读取。启动相关配置在 UI 标明重启生效；命令行显式参数优先于文件，UI 标明覆盖来源。资料库时区不能因迁移或省略而随设备改变。

「设置」与「数据同步」为独立页面，导航中设置在前、数据同步在后。两页均平铺全部分区，不使用隐藏内容的标签页，保证浏览器搜索可达；悬浮目录在宽屏右侧竖排，窄屏回到正文上方，只负责页内定位；分区以标题和留白区分，不加横向分割线。设置标题、重新加载和保存操作吸顶，目录及分区跳转按顶栏实际高度避让。数据同步保留同步状态、待提交修改、冲突、离线内容和本机操作；连接和缓存策略移到设置并提供链接。统一用户文案为「本机 / 远端」。空队列不意味着远端没有更新，不虚构上次同步时间。

### 默认时区与投影方式

新格式省略资料库时区时固定使用 UTC；初始化仍优先写入探测到的 IANA 时区。旧格式依赖系统时区的配置在迁移时固定为当前 IANA 时区，无法确定名称时明确要求配置后再迁移，不能静默按 UTC 解释旧数据。

旧实现启动时总重新选择最快的链接方式，不适合现在允许用户编辑的设置：用户指定 copy 会被重新改回 reflink。现在显式方式在启动时验证，不可用时报错；省略时自动探测而不写回。没有选择静默降级，是为了不把用户指定的空间占用和隔离语义悄悄改变。已有投影不会因改设置自动重建，可用 relink 重建。

2026-10-23 用户要求暂时移除网页中的修复来源配置，待后续研究。设置 API 不再公开此可编辑字段；既有 `[[remote]]` 配置和命令行修复能力保留，保存其他设置时不删除已有来源。

容量设置的网页输入使用现有依赖 go-humanize 解析带单位字符串，设置 API 同时兼容整数；TOML 仍保存整数字节，不改变旧配置语义。GB/G 为十进制，GiB/Gi 为二进制。网页只用能精确还原的单位显示容量，避免编辑时因四舍五入悄悄改变限制。启动参数覆盖提示与恢复默认同行，并使用主题色。

地图相关配置独立为「地图」分区。存储区新增本机原文件、资料信息（数据库、操作记录和辅助索引）、缩略图与预览缓存的只读统计；使用独立请求及手动刷新，不阻塞设置加载或保存。按现有文件长度汇总，排除 boxes 投影及上传/下载工作区等临时数据，不声称是文件系统分配块的精确占用；不跟随符号链接。离线端只计算本机留存及下载内容，按派生描述将共享缓存对象区分为原文件和预览，同一对象只计一次。扫描允许并发变化，可取消、不写日志或缓存状态，不构建新的持久索引。

访问凭据支持可选备注，创建时填写、之后可编辑或清空，保存在同一条 kist.toml 授权记录中。备注是展示信息，修改不生成新 token、不改摘要、ID 或创建时间；旧无备注凭据继续有效。撤销后的记录不可通过修改备注重新创建。备注长度最多 200 个字符，列表只返回备注及非秘密身份信息。

凭据列表采用紧凑表格，备注、ID 和创建时间分列，编辑/撤销在最右侧；行间轻分隔并支持整行悬停和键盘焦点背景。创建入口位于列表上方，点击后展开行内备注表单，确认或取消后收起，避免常驻输入框与既有凭据混淆。
