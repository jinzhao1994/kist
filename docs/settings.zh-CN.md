# 实例设置

主库和离线客户端都通过主导航的「设置」修改当前实例的 `kist.toml`，两端配置不会随数据同步互相覆盖。「显示设置」仍保存浏览器自己的语言、格式、显示时区、阅读方向和明暗模式；主色移到实例设置。

文件可以很短：省略的选项取默认值，「恢复默认」在保存时删除显式配置。初始化通常只写版本、模式、身份、时区及投影方式。保留生成的身份信息，不要把同一客户端身份复制给另一个独立客户端。

设置分为外观、存储、服务、地图、连接（客户端）和访问凭据。主库与客户端都可创建自己的下游凭据。存储包含缓存保留时间和体积，或主库的时间解释时区、投影方式；服务包含监听地址、网页来源及上传限制。页面标明默认值及重启生效项。显式命令行参数优先于配置文件，页面显示当前覆盖值；参数不会反写配置。投影方式改变后已有文件不会自动重建，必要时运行 `kist relink`。

例如，在已有配置中添加：

```toml
[appearance]
primary_color = "green"

[server]
listen = "127.0.0.1:8473"
```

主色支持 gray、green、yellow、pink、blue、orange。服务默认监听回环地址，主库端口 8473、客户端 8474；上传批次上限 32 GiB、1000 个文件。客户端 `[client]` 下缓存默认 `cache_max_age = "180d"`、`cache_max_bytes = 10737418240`。缓存上限不逐出已保留离线的内容、待提交操作或新导入原件。缩减限制在后续缓存维护中执行；客户端服务启动时及每小时自动清理，离线时同样执行。需要立即清理时仍可使用原有 CLI 和 API。

新格式省略 `library.timezone` 时使用 UTC，初始化优先写入探测到的 IANA 时区。修改只影响之后对无时区时间戳的解释，不重写已有操作。旧格式依赖系统时区的配置会在迁移时固定为当前 IANA 时区；无法确定时要求手动明确后再继续。

`library.language` 是资料库的描述生成语言，独立于浏览器界面语言。默认 `zh-CN`，支持 `en`、`zh-Hant` 等 BCP 47 标签。修改只影响之后的生成任务，不改写已有描述；每条描述保留生成语言。

保存先校验整个配置，再原子替换私有文件；未知键和无效值被拒绝。页面打开后若配置已被别处修改，会保留编辑并提示重新加载，不覆盖别人写入的内容。普通注释和未修改行尽量保留，复杂 TOML 可能重新格式化。

升级前停止旧进程并备份配置。首次打开会迁移旧 `client.json`、`connection.json`、`sync-access.json`，完整写好新配置后才删除旧文件；未知旧版本拒绝迁移。旧二进制不能读取版本 2 的配置。

`kist.toml` 可能含连接凭据及凭据摘要，须按私密文件保管。设置 API 不回显已保存的秘密；新凭据只显示一次，重新连接需再次输入凭据。待同步操作、已下载目录、缓存索引及离线保留选择属于运行状态，仍独立保存。

容量设置支持 `32 GB`、`32G`、`32 GiB` 等写法。GB 按 1000 进位，GiB 按 1024 进位；保存到配置文件时仍是整数个字节。显示值不会用四舍五入后的容量替代原值。「允许使用的访问网址」填写用于打开 kist 的网址（协议、主机和端口，不带路径），每行一个；仅本机访问可留空。

地图选项独立显示在「地图」分区。存储分区显示本机原文件、资料信息及缩略图与预览缓存的文件大小，可手动刷新。统计包含历史版本及本机已下载内容，不含目录投影副本和临时数据；实际磁盘分配空间可能因压缩或共享块而不同。

访问凭据可填写备注，用来区分不同用途或客户端。备注可随时编辑或清空，不影响原凭据；旧凭据无需重新创建。

保存后配置即时生效，只有监听地址需要重启。修改地图配置后页面会自动刷新，以加载新的资源访问策略。Linux/macOS 手动编辑配置后，可用 `kill -HUP <PID>` 让服务重新读取；无效配置不会替换正在运行的服务配置。Windows 可通过网页保存应用修改，或编辑文件后重启。已有上传会话继续完成；投影方式和时区变更不批量修改已有文件及历史记录。
