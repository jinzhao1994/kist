# kist v0.1.5

Read more kinds of archived files directly, identify boxes by their covers, and
browse with clearer metadata and consistent context menus.

## Changes

- Preserve complete image and video thumbnail proportions. Recognize MOV files
  and generate PDF first-page thumbnails. Video thumbnails prefer embedded cover
  art or a valid QuickTime cover timestamp, then sample up to 100 distributed
  frames within a time budget to avoid black frames and choose a representative
  image.
- Read PDF, DOC/DOCX and PPT/PPTX with a paged PDF.js reader, text selection,
  search and zoom. Open the original PDF or converted document in a new browser
  tab alongside the original-file download. Center documents on wide screens and
  eliminate document-opening flashes. Image details use browser-supported
  original images and provide a native new-tab link.
- Preview ASCII/binary STL models and GPX tracks, routes and waypoints. GPX uses
  configurable OpenFreeMap and terrain backgrounds, with a track-only fallback
  when map services are unavailable.
- Read plain text and source files with syntax highlighting, line numbers,
  wrapping and encoding controls, including Unicode and legacy Chinese text.
  Click or drag line numbers to select ranges reflected in shareable URLs;
  click the selected line again to clear it. Text thumbnails render excerpts
  without storing raster images.
- Render Markdown with preview/source switching. Preview XLS, XLSX, CSV and TSV
  in a read-only spreadsheet viewer, including multiple worksheets and cell
  selection/copying. Spreadsheet formulas are not recalculated.
- Set a box cover from a file's context menu, including in All files. Medium and
  large box cards reuse the file preview without cropping. Remove a cover from
  the box menu without deleting its file. Covers follow file renames/content
  updates, disappear temporarily when their file is trashed, and return on
  restore. Cover changes support strict undo and log replay.
- Maintain folder and box logical byte totals in SQLite as files change, rather
  than scanning all descendants when browsing. Totals include repeated file
  references and exclude recycled files.
- Add file tag actions to context and row menus; show compact text-only tags in
  file cards/lists and box lists. Add background, box, folder and breadcrumb
  context actions for creation, uploads and management. Improve dialog focus,
  tag assignment, breadcrumbs and recycle-bin scope selectors.
- Remove duplicate file-name subtitles. In All files, prioritize the source box
  name over its compact date, with a pointer-following full-name tooltip. Keep
  file sizes aligned and compact box descriptions, dates and tags. Simplify
  filter URLs while preserving existing links.
- Refresh Docker base images and installed runtime packages on every release.
  Images include LibreOffice Writer/Impress and Poppler for document previews.

## Upgrade

Existing v0.1.x libraries can be opened directly. Stop the old service and other
writers, replace the binary or recreate the container, then refresh browser
pages. Startup automatically applies the transactional schema migrations for
folder totals and box covers (schema 6). Folder totals are backfilled once from
indexed file sizes; no original files are scanned. Existing boxes start without
covers. There is no destructive migration or need to reinitialize the library.
Keep normal scheduled backups; a new full-library backup or full blob scrub is
not required for this compatible forward upgrade.

The database schema and cover fields in operation payloads are newer than
v0.1.4. Older binaries are not a supported reader for an upgraded library and
may refuse its schema or fail to preserve cover semantics. Do not downgrade by
replacing only the executable or rebuilding with an older version. If rollback
is required, keep a pre-upgrade recovery point and restore that matching library
with its older binary.

New video thumbnail recipes generate on demand without reusing the old recipe's
cache. Existing valid image/PDF previews remain reusable; clearing `derived/`
is not necessary. Old MOV files can be reclassified by running
`kist extract --extractor media` or using the metadata extraction action.

Pull `jinzhao1994/kist:v0.1.5` or `ghcr.io/jinzhao1994/kist:v0.1.5` and recreate
the container while preserving its library mount, UID/GID, ports and trusted
origins. Binary assets, versioned images and `latest` promotion finish separately;
use each registry's tag after its verification succeeds. Native packages cover
Linux x86-64, macOS Intel/Apple Silicon and Windows x86-64. Verify downloads
against `SHA256SUMS`. Images support Linux amd64 and arm64.

## Limits

Standalone binaries need optional external tools for some previews: LibreOffice
Writer/Impress and Poppler for Word/PowerPoint, Poppler for PDF thumbnails, and
FFmpeg/libheif for supported video/HEIC operations. The Docker image bundles
these dependencies. Unsupported, damaged or oversized files remain downloadable.
PDF.js selects existing text; scanned-page OCR depends on the browser's native
reader when opened in a new tab and is not saved to the archive.

GPX backgrounds require access to external map/tile services. Original GPX files
stay local, but requested tiles reveal the viewed region to those services.
Text and spreadsheet previews have resource limits; truncated results are
identified in the reader. STL previews are static, not a printability check.
There is no built-in login; use a trusted network or authenticated reverse
proxy. Historical originals are retained permanently; deletion does not reclaim
disk space.
