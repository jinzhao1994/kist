# kist v0.1.1

A compatibility-preserving update with a refreshed file browser and safer
concurrent blob writes.

## Changes

- Move file search and filters above the file grid. Add editable, removable
  conditions for media types, capture dates and all/any/excluded tags.
- Load additional files automatically while scrolling, with loading, retry and
  final file-count states. Desktop navigation and content scroll independently;
  mobile grids follow page scrolling.
- Adopt Mantine controls with six primary colors and light/dark/system modes.
  Existing appearance preferences migrate automatically. Display settings apply
  immediately, with searchable locale and timezone choices.
- Fix a blob publication race between concurrent imports and repairs.
- Add public multi-architecture GHCR releases, verified `latest` and `edge`
  channels, and a Synology Container Manager deployment guide.
- Update dependencies, cross-platform checks and visual regression coverage.

## Upgrade

There are no operation-log, library configuration or database schema changes in
this release. Existing v0.1.0 libraries can be opened directly; do not initialize
an existing library again.

Stop all writers and back up the complete library before upgrading. Keep the
existing library mount, UID/GID, port and trusted-origin settings. Pull
`ghcr.io/jinzhao1994/kist:v0.1.1` and recreate the container, or refresh `latest`
after its separate image verification workflow succeeds. The binary release,
versioned image and `latest` promotion complete in that order.

Native packages are available for Linux x86-64, macOS Intel/Apple Silicon and
Windows x86-64. Verify downloads using `SHA256SUMS`.

## Unchanged boundaries

There is no built-in login. Use a trusted network or an authenticated reverse
proxy. Journals and original files are retained permanently; deleting an item
does not reclaim its disk space. Unsupported media remain downloadable.
