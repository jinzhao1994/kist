# kist v0.1.6

Keep related originals together with file combinations: Live Photos, videos with
subtitles, and multipage documents.

## Changes

- Configure an existing folder as a file combination with its own display name,
  automatic or explicit primary file, and ordered members. Original files remain
  individually accessible; converting back to a folder preserves them.
- Read multipage combinations in the file detail viewer. Reorder pages with a
  compact drag-and-drop list, and optionally leave some files out of pagination.
  The current page is preserved in the URL and its own tags and metadata appear
  in the details panel.
- Nest combinations inside multipage documents. A Live Photo occupies one page;
  nested multipage documents expand into one continuous reading sequence with
  a single page toolbar. The stored hierarchy and member order remain intact.
- Preload Live Photo motion and play it in place using the Live button. Playback
  finishes on the still photo without opening a separate video player.
- Load multiple SRT/WebVTT subtitle tracks for a video. Use the player's native
  subtitle controls to switch languages or turn subtitles off, including in
  fullscreen. A failed subtitle does not prevent other valid tracks from loading.
- Show combinations as single search results using their primary file's
  attributes. Enable “Include combination files” to find other members
  independently. Members retain their own tags and metadata; combinations do
  not introduce a separate annotation store.
- Choose a directory or shared-prefix filesystem projection. Flat projections
  resolve naming collisions while keeping video and subtitle prefixes aligned.
  Configuration changes support atomic updates, strict undo, history, replay,
  library rebuild and deep integrity verification.
- Refine combination navigation, configuration dialogs and filename indicators.
  Preserve separate sidebar and content scrolling while allowing horizontal
  browser history gestures.

## Upgrade

Existing v0.1.x libraries can be opened directly. Stop the old service and other
writers, replace the binary or recreate the container, then refresh browser
pages. Startup automatically adds the fileset tables and operation index in a
transactional migration to schema 7. Existing folders remain ordinary folders
until explicitly configured. Original blobs and existing logs are not rewritten;
there is no destructive migration or need to reinitialize the library. Keep
normal scheduled backups; this compatible forward upgrade does not require a
new full-library backup or full blob scrub.

Older binaries do not support schema 7 or the new fileset operation payloads.
Do not downgrade an upgraded library by replacing only the executable or
rebuilding with an older version. For an older-version rollback, restore a
pre-upgrade recovery point together with its matching binary.

Pull `jinzhao1994/kist:v0.1.6` or `ghcr.io/jinzhao1994/kist:v0.1.6` and recreate
the container while preserving its library mount, UID/GID, ports and trusted
origins. Binary assets, versioned images and `latest` promotion finish separately;
use each registry's tag after its verification succeeds. Native packages cover
Linux x86-64, macOS Intel/Apple Silicon and Windows x86-64. Verify downloads
against `SHA256SUMS`. Images support Linux amd64 and arm64.

## Limits

Combinations are configured manually; this release does not automatically pair
iPhone Live Photo imports. Live Photo image/video roles and video/subtitle roles
refer to actual files; only multipage members can reference child combinations.
Playback uses browser-supported media and available derived previews. Standalone
binaries still need optional FFmpeg/libheif tools for relevant media operations;
the container image includes these tools. Subtitle previews support UTF-8 SRT and
WebVTT files up to 4 MiB per track.

The default search uses the primary file, not every member's content or tags.
Changing the primary changes the representative attributes without moving any
member's annotations. General-purpose metadata query expressions remain outside
this release. There is no built-in login; use a trusted network or authenticated
reverse proxy. Historical originals remain permanently retained.
