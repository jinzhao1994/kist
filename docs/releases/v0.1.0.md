# kist v0.1.0

First release of the self-hosted personal archive: organize photos, video and
paperwork in boxes, then retrieve them through a global tag tree.

## Included

- One Go binary with SQLite and an embedded English/Chinese web interface.
- Content-addressed originals, append-only operation journals, and a
  human-readable file projection. The database is fully rebuildable.
- CLI and browser imports, metadata extraction, tag and date filters.
- On-demand thumbnails, HEIC previews and H.264/AAC video previews; Docker
  includes the required media tools, while native binaries detect optional tools.
- Operation history, read-only historical boxes, file version comparisons,
  strict undo and whole-event recycle-bin restoration.
- Integrity verification, full-content scrubbing, repair from another blob
  copy and database/projection reconstruction.
- Six themes with light/dark/system appearance and browser-local display settings.

## Install

Choose the archive for macOS Apple Silicon, macOS Intel, Linux x86-64, or
Windows x86-64. Verify it against the accompanying `SHA256SUMS`, then extract
and run `kist version`. Each archive includes its license and operations guide.

Docker users can build the included Dockerfile and start with Compose; no
registry image is published by this release workflow. See the repository README.

## Boundaries

There is no built-in login: use loopback access, a trusted network, or an
authenticated reverse proxy. Binaries are not signed or notarized. ARM Linux
and Windows ARM are not included in the v0.1 binary matrix.

v0.1 retains journals and originals permanently: deletion hides content and
does not free its disk space. There is no garbage collection or retention timer.
Historical queries replay the log and have a 30-second request deadline.
Uploads default to 1,000 files and 2 GiB per batch. Unsupported or oversized
media keep original downloads instead of a preview.

This is the first released compatibility baseline. Intermediate development
libraries are not all guaranteed compatible. Back up `kist.toml`, `ops/` and
`blobs/` with all writers stopped, then verify a separate restored copy before
entrusting the archive with the only copy of your data.
