# kist v0.1.2

Browse archives in multiple layouts, explore files in a full-screen gallery,
and find boxes alongside files through shared tags.

## Changes

- Add large, medium and small icon layouts and a list layout for boxes and files,
  with separate saved preferences.
- Replace file preview dialogs with a gallery supporting keyboard navigation,
  mobile swipes, automatic pagination, details and return-to-list scroll recovery.
  Opening and closing animate from the thumbnail, respect reduced-motion settings,
  and preserve loaded thumbnails to avoid flashing on return.
- Show file details by default on desktop, with a subtle edge toggle and the
  kist logo in the gallery header.
- Fix visible thumbnails beyond the first eight staying as placeholders. All
  visible thumbnails now load while offscreen content remains virtualized.
- Add box search, tag filtering and automatic pagination. Tag results include
  both matching boxes and files, with distinct counts and deduplicated subtree totals.
- Add whole-box deletion to the recycle bin and complete restoration.
- Use a collapsed tag tree and readable ancestor paths in tag selectors.
  Keep the selected parent when creating consecutive child tags.

## Upgrade

Existing v0.1.0 and v0.1.1 libraries can be opened directly. There are no database
schema or library configuration changes. Do not initialize an existing library again.

This release adds `delete_box_contents` and `restore_box_contents` journal actions.
Older binaries cannot replay these new actions. Once whole-box deletion or restoration
has been used, keep v0.1.2 or newer; rollback to an older binary requires restoring
its matching pre-upgrade library backup, not just replacing the executable.

Stop all writers and back up the complete library before upgrading. Preserve the
library mount, UID/GID, port and trusted-origin settings. Pull
`ghcr.io/jinzhao1994/kist:v0.1.2` and recreate the container, or refresh `latest`
after its image verification workflow succeeds. Binary assets, the versioned
image and `latest` promotion complete in that order.

Native packages cover Linux x86-64, macOS Intel/Apple Silicon and Windows x86-64.
Verify downloads against `SHA256SUMS`. Container images support Linux amd64 and arm64.

## Unchanged boundaries

There is no built-in login. Use a trusted network or an authenticated reverse
proxy. Original files and journals are retained permanently; deletion does not
reclaim disk space. Unsupported media remain downloadable.
