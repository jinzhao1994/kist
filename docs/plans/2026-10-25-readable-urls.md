# 可读 URL、永久链接及文件更多操作

## 范围与约束

权威语义见设计文档的「2026-10-25 可读 URL 与永久链接」。仅本地实现、验收和提交，不推送 GitHub，不等待 CI。

- 日常地址采用 `/boxes/<现有投影盒名>/<逻辑路径>`，逐段恰好一次编解码；盒名复用日期精度、净化和重名规则。
- 盒永久地址为 `/boxes/id/<ID>`，旧 `/boxes/<ID>` 兼容并保留定位参数及锚点。
- 文件／组合永久地址为 `/files?file=<ID>`，目录为 `/files?folder=<ID>`，不依赖祖先身份。
- 可读路径只表示当前位置，不保存别名；ID 表示对象最新状态，不是历史快照。
- 组合默认详情，`view=folder` 打开成员目录；保留页码、嵌套组合和当前列表范围。
- 两端共用逻辑目录解析，不要求磁盘投影或原文件缓存。没有 schema、op 类型或冗余索引变化，schema 仍为 8，无需 migration。
- 文件操作复用同一个更多菜单，区分整个组合与当前页；复制链接使用当前 origin。

- [同一盒永久地址](http://127.0.0.1:19603/boxes/id/01a16a65-522a-7daf-960a-ad239a94a13d)
- [客户端多页证件可读地址](http://127.0.0.1:19604/boxes/2026-10-22_%E7%A6%BB%E7%BA%BF%E9%AA%8C%E6%94%B6%20%C2%B7%20%E8%B5%84%E6%96%99/%E5%A4%9A%E9%A1%B5%E8%AF%81%E4%BB%B6)
- [同一组合永久地址](http://127.0.0.1:19604/files?file=01a163fd-1920-7cb5-8965-135beb84f998)

1. 从盒或目录打开文件，确认地址包含名称，右上角操作收进“…”菜单。
2. 在组合中翻页、打开侧栏，复制两种链接，再切换永久链接并刷新；当前页和浏览范围保持不变。
3. 通过组合菜单查看全部文件，再返回组合；测试浏览器前进后退。改名后从普通导航取得新地址，旧永久链接仍定位同一对象。
