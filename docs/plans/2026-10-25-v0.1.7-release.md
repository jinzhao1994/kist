## 审查修正

1. **P1，中继异常响应的确定性边界（置信度 10/10）**：
   `internal/syncclient/relay.go` 原先接受“成功保管回执 + 拒绝错误”矛盾信封，
   或缺少 code/class 的拒绝信封，将结果标为确定拒绝；这可能允许放弃已交给
   中继的操作。现与主库提交相同，成功与明确拒绝必须互斥且完整，其余保留
   结果不确定。新增 12 种信封回归；用旧实现 overlay 复现 5 项失败，修复后
   `go test -race ./internal/syncclient -count=1` 通过。
2. **使用文档过期**：移除开发版/未完成描述、旧标签页/手动清理说明，统一
   `180d` 缓存默认值及当前入口，补充离线历史和回收站。安装包加入中英离线
   与设置指南，打包测试同时验证两种格式和校验和；同步更新发行烟雾测试的安装包成员校验。
3. 发行说明明确 schema 8、配置 v2、新同步日志及 pending 格式的前向升级和
   回退边界。常规升级无需重新建库、全库备份或 blob scrub；需要旧版回退时
   才要求升级前恢复点。

4. **Windows 导航测试夹具**：运行 `40188006997` 的 Windows 测试在宿主磁盘
   创建含 `?` 的文件名时失败。改为 `PrepareFiles` 的普通暂存路径与逻辑归档
   路径分离，保留特殊字符往返、路径复用、客户端解析等原有断言；不跳过
   Windows，也不缩减名称覆盖。聚焦 `TestNavigation`、完整检查及最终候选的
   Windows CI 均通过。
