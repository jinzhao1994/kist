# 缩略图完整显示与视频封面验收

本记录是已完成工作的交付证据；行为约定以设计文档 3.6 与 5.5 为准。

## 完成范围

- 图片、视频封面与 PDF 首页在网格、列表及画廊过渡中完整显示，允许留白；没有预览能力的文件仍显示类型图标和下载入口。
- MOV 按内容识别为 QuickTime，使用 FFmpeg；PDF 使用 Poppler 生成第一页静态预览。Docker 内置相关工具，原生部署保留缺依赖提示与恢复。
- 视频封面依次尝试内嵌图片、有效 QuickTime poster time、分散采样。最多 100 个低分辨率候选，排除黑场并按颜色直方图选代表帧；短片减少采样，慢设备受预算限制。不保证语义上的最佳镜头。
- 新视频缩略图使用 `video_thumb_512_v2`；图片、PDF 和详情配方保持不变。缓存按 blob 与 recipe 隔离，旧视频缓存存在也不能满足新请求。
