# M7 文档、打包与发布收口

权威范围：设计文档 §7 M7。四个平台沿用既定的 darwin/arm64、darwin/amd64、linux/amd64、windows/amd64；不改变库格式或业务语义。

## 交付与验收

1. 修复发布流程过期的 Intel Mac runner，对实际交叉编译产物做校验和、初始化、导入、撤销/恢复、重建、深度检查、scrub、内嵌网页资源及当前/历史文件下载验收。Release 在打包前执行 `make check`。
2. 整理可安装的发布包、校验和、安装/升级/备份恢复说明及版本说明，核对双语 README 与当前实现。
3. 无标签演练 GitHub Actions，确认四平台产物可执行；Docker 继续验证内置媒体依赖与持久化。
4. 全部准备可审阅后，按根目录 AGENTS.md 的发布授权要求确认 v0.1 正式发布，再验证实际发布资产。

## 当前证据

- 原 smoke 仅运行 `version`，不能证明 SQLite 或内嵌资源可用；新增 `scripts/release-smoke.py` 使用临时库和仓库外工作目录。
- 原 `macos-13` runner 已退役，替换为官方支持的 `macos-15-intel`。来源：https://github.com/actions/runner-images/issues/13046 。
- 第一阶段 `a8be63e` 的 CI、Visual 均通过；[Release 演练 38013741994](https://github.com/jinzhao1994/kist/actions/runs/38013741994) 的 Linux、Intel Mac、Apple Silicon Mac、Windows 实际二进制测试全部通过。
- `make dist` 产出四个压缩包与 SHA256SUMS，包含可执行文件、LICENSE、双语 README 和 `docs/operations.md`。保持文档相对路径，避免包内安装说明链接失效。
- `scripts/release-smoke.py` 进一步直接读取安装包，验证 SHA256、成员、版本及源提交号；仅从 ops、blobs 与配置恢复新库后再次 rebuild/relink/verify/scrub，并启动恢复库的服务验证下载。
- 本机安装包、只复制权威数据的恢复验收及完整 `make check` 均通过。安装包版本的远程四平台演练仍待最终确认。
- 安装/升级/回退手册见 `docs/operations.md`，待发布说明见 `docs/releases/v0.1.0.md`，发布流程见 `docs/releases/README.md`。目前尚未创建标签、GitHub Release 或 registry 镜像。
