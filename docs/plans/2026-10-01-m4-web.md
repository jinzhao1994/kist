# M4：HTTP API 与多语言 Web UI

状态：实施中。权威决策见设计文档 §5.5；本文件记录交付顺序与验证证据，不覆盖设计。

## 完成条件

一个 kist 二进制可以启动本地服务，在中英文界面中完成 box 创建与编辑、文件上传、网格浏览、文件详情与预览/下载、tag 创建/改名/移动/删除及 box/file 标注、组合检索。API 有 OpenAPI 契约；CLI 与 Web 同库并发安全。原文件不支持预览时有明确降级。

界面语言、地区格式、时区与文字方向独立建模；中英文翻译完整，地区格式有测试，RTL 布局有浏览器验证。不是把中文硬编码后再包一层语言选择器。

## 交付顺序

每阶段先针对性测试，再 `make check`、中文 commit、push、对应 GitHub Actions 全绿。文档阶段运行 `git diff --check`。不合并阶段以跳过 CI。

## 测试原则

行为测试断言用户可观察结果、权威日志数量与恢复一致性；不只断言 mock 被调用。不用生产实现同时生成旧样本和预期。HTTP 测试使用临时真实库，浏览器测试使用隔离库及合成文件。每个实际发现的缺陷先补失败用例再修复。

国际化测试检查消息键与占位参数一致，不能把 RTL 测试等同于只检查 `dir` 属性；必须在浏览器检查侧栏、表单、对话框、溢出和阅读顺序。地区格式不改变库的排序与游标契约。

## 范围边界

M5 才做派生缩略图、ffmpeg、转码；M6 才做历史快照界面。运维命令保持 CLI。M4 不引入登录、分享、后台任务框架、GC 或多设备同步。若用户选择扩大这些范围，先更新权威设计及本计划。
