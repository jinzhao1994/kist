# 本机运行状态 SQLite 迁移

## 已交付

- 独立 `runtime.db`，与可重建归档数据库分开；FULL/WAL、实例身份、版本与缺失保护。
- 提取和媒体任务共用 `background_jobs`；`job_attempts` 保留执行与错误、模型结果；暂停和扫描游标放在 `queue_controls`。
- 上传会话与逐文件偏移、缓存对象与派生索引、离线保留关系、工作空间预留、同步边界、pending 查询投影和 Photon 限流分别建表。
- archive 与 pending 日志、原文件、暂存字节和配置保持原有职责；网络与渲染不在 SQL 事务中运行。
- 旧 JSON 按子系统锁与事务一次导入，保留备份，不双写、不重复回退；失败可重试。停止全部旧进程后升级，配置标记阻止旧程序重新打开。
- 新增执行记录列表与详情 API，列表不返回模型正文，详情通过文件、任务类型和请求 ID 定位。

## 验收证据

使用仓库内合成样本；没有提交个人文档、原图、模型私密返回或令牌。

- `npm --prefix web ci` 与 `make check` 通过：409 项前端测试、API 契约、构建、格式、vet、全仓库 race 测试和单二进制构建。
- 相关包完整回归：`internal/library`、`internal/upload`、`internal/api`、`internal/runtimestore`、`internal/arch` 通过。
- 迁移：旧任务重启保留，归档 rebuild 不清空运行状态；删除任务后不从 JSON 复活；损坏导入回滚；数据库缺失、未来版本、错误实例身份被拒绝。
- 上传：既有进程死亡与 fsync 边界测试通过；旧 JSON 会话导入后按 SQL 偏移截去未确认尾部，恢复续传，旧备份不改写。
- 缓存与同步：保留选择及字节数、损坏修复、未同步意图、中继、同步与历史回归通过。
- 执行历史：失败重试使用新请求，旧返回保留；成功返回也记录；明确详情读取、分页与任务类型隔离；UTF-8 截断与私有权限。
- 10,000 项合成队列的查询计划检查：单项状态、调度候选、执行历史使用索引，无全表扫描或额外排序。

完整实例恢复需包含运行库；归档专用备份无法恢复本机任务与选择。具体步骤见 `docs/operations.md`。
